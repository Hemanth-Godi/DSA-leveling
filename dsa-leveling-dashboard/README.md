# DSA LEVELING — Dashboard

Frontend-only dashboard prototype built with React, Vite, TypeScript, Tailwind CSS, and lucide-react.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Structure

- `src/pages/Dashboard.tsx` — dashboard composition
- `src/components/dashboard/` — reusable dashboard UI components
- `src/data/mockDashboard.ts` — all mock user/progression data
- `src/types/dashboard.ts` — TypeScript data types
- `src/assets/` — supplied artwork assets

No backend, authentication, database, or API calls are included.
